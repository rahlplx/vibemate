## 2026-07-01 - Optimizing LRUCache Correctness and Collection Methods
**Learning:** In JavaScript, `Map` insertion order corresponds directly to iteration order. When implementing an LRU cache with a standard `Map`, calling `.get()` or `.has()` must delete and re-insert the entry to move it to the end (the MRU position) so that `.keys().next().value` yields the true Least Recently Used (LRU) entry. Chaining `.entries()`, `.filter()`, and `.map()` on an array created from a map introduces massive overhead via redundant allocations and multiple passes. Simple `for...of` loops provide high performance with minimal memory footprint.
**Action:** Always delete and re-insert entries in `Map`-based LRU caches upon access. Use single-pass direct loop iteration for collections (`keys()`, `values()`, `entries()`) instead of chaining high-level array helper methods.
